About this unified app

This single HTML contains two complete bots as isolated sections. Each keeps its own features, storage and exports. Open Bot A or Bot B from the bottom bar.

  • Update cycle: a GitHub Actions workflow (unified-status.yml, cron every 5 minutes) probes the free public sources both bots use and publishes status.json to the unified-data branch. This page reads that file.
  • What the collector proves: only that those public sources answered, how fast, and when. It does not scan tokens and does not publish a fresh HTML.
  • Honest limits: GitHub can delay or queue scheduled runs (observed tonight). The page shows the file's own timestamp; if it is old it says UPDATE DELAYED or UPDATE FAILED. Token scans run inside each bot only while this page is open.
  • Labels: DATA INCOMPLETE = some sources failed. UPDATE FAILED = all sources failed or data is very old. NOT OBSERVED = no data seen.
  • Paper only. No wallets, keys or trades. Bot sections keep their own DEMO DATA labels.
