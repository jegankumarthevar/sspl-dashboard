Method, limits and Android use

operator guide
Data sources and trust boundary

This build uses only free public endpoints: GeckoTerminal for new pools, pool detail and recent pool trades; DexScreener for token market state; Jupiter for sparse round-trip quotes; RugCheck for token risk reports; and a public Solana RPC endpoint for limited mint-authority and wallet-history checks. No API key, private key, wallet connection, paid indexer, trade execution or hidden backend is included.

Every source can fail. The app treats a source failure as missing evidence, not as success. A 429 is rate limited and backed off. A browser status-0 failure can be CORS, network or public gateway trouble; the UI labels the affected source unavailable and leaves the token DATA INCOMPLETE instead of inventing a value.

Source timestamps matter. Pool creation time from GeckoTerminal is the observed source age. First-seen time is when this app first observed the mint. They are not the same thing and neither proves the true global launch time.

Early-entry gate meaning

The score is evidence ranking, not financial advice. It combines early age, liquidity, short-window activity, risk status, source-reported holder distribution, recent wallet breadth and source coverage. Hard risk gates override the score, so a token can score high and still be rejected. Those rows are labelled REJECTED BY RISK GATE in the command center.

When mint or freeze authority is still present, the token is rejected. When RugCheck reports danger, the token is rejected. When holder data is missing for a brand-new token, the app does not hard-reject on an unverified top-holder number; it awards no holder points and marks the holder state unknown.

Wallet evidence is capped for very young tokens because creator, deployer or bundler buys can look like independent demand. A small recent trade sample cannot prove a smart-money wallet. Quality labels describe the observed sample only.

2x to 5x target monitor

The target monitor compares the latest sampled price with the signal reference price. A target is marked observed only after the running page sees the level. If a token spikes and falls between scans, the app does not claim that it saw or could have captured the spike.

Distance bars show how far the latest sampled price is from the next target. They are not ETA predictions. The app never invents a time-to-target because the public data does not support that claim.

Jupiter quote results, when available, are shown separately as a sparse executable-cost check. A failed quote or NO_ROUTE is evidence of limited tradability at that size, not a simulated profit.

Android operating flow

Use the bottom tabs for Radar, Command, Targets, Ledger and Health. Search and status filters are on Radar. Sort, minimum score, theme, fee and slippage are persisted locally. Buttons are large enough for touch use and the layout is designed to avoid horizontal page overflow on narrow screens.

Press Scan now after changing source settings. Auto scan runs only while the page is open. Watchlist alerts are in-page toast and Web Audio alerts only. Closing the tab stops them; true push alerts need a backend service, which this free single-file build intentionally does not fake.

Use Export JSON or full backup before clearing site data. Import backup restores local state into this browser. Export diagnostics creates a source-health JSON that can be shared without any credential because no credential is stored in the file.

Paper ledger and economics

Paper entry creates a local $10 tracking entry at the latest observed price. It is not an order and cannot move real funds. The economics panel applies configurable fee and slippage percentages on both entry and exit to show a more honest net estimate.

Outcome history compares all tracked signals with candidate-labelled signals. The candidate edge remains NOT PROVEN until the sample is large and the methodology accounts for selection bias, quote depth, failed routes and timing gaps. A positive median in a small sample is only an observation.

What is not included

No paid data source is used. No Helius key or other key-needing source is embedded. No private wallet is requested. No real trade is placed. No background service, push notification, closed-page monitoring or guaranteed exit is claimed.

Historical wallet skill, wallet independence and common funding remain hard problems on free public data. The app can show recent trade behavior and optionally sample public RPC transaction history, but it labels those results as hints rather than proof.
